# RootScope Android

Нативный Android-сканер в режиме только чтение. Цель — собрать доступные системные сведения, а не получить root.

## Что собирает
- модель, сборку, fingerprint, версию Android/SDK, патч безопасности, ядро, ABI;
- доступные `getprop` свойства, включая признаки Verified Boot, lock/vbmeta, USB/ADB;
- доступные сведения SELinux, `/proc/cmdline`, подходящие строки `/proc/mounts`;
- проверку наличия некоторых известных root-путей и поиск имён пакетов-индикаторов;
- список установленных пакетов (с разрешением `QUERY_ALL_PACKAGES`);
- JSON-отчёт, сохраняемый через системный диалог выбора файла.

## Ограничения
- обычное APK не может гарантированно читать закрытые свойства загрузчика, все разделы, vendor-данные или историю аппаратной аттестации;
- отсутствие `su`/Magisk-признаков не доказывает отсутствие root;
- приложение не проверяет CVE эксплуатацией и не утверждает уязвимость только по номеру версии;
- fastboot можно исследовать только в соответствующем режиме/при подключении, не из обычной сессии Android;
- не получает IMEI, номер телефона, MAC-адрес, геолокацию, контакты или сообщения;
- не содержит интернет-разрешения и не отправляет отчёт наружу.

## Сборка APK
Проект использует Android Gradle Plugin 8.7.3, Kotlin 2.0.21, Gradle 8.9, SDK 35, JDK 17.

### GitHub Actions
1. Создайте пустой репозиторий на GitHub и загрузите содержимое этой папки.
2. Откройте **Actions → Build RootScope APK → Run workflow**.
3. После успешной сборки скачайте artifact `RootScope-debug-apk`; внутри будет `app-debug.apk`.

### Локально
При установленном JDK 17, Android SDK platform 35 и Gradle 8.9 выполните:
`gradle assembleDebug`

APK: `app/build/outputs/apk/debug/app-debug.apk`.

Сборка в этом архиве не подписана релизным ключом: debug APK подходит для личной установки и диагностики.
